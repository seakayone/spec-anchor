Reports problems with scenario slugs in OpenSpec capability specs:
  • an <a in a #### Scenario: heading that is not exactly <a id="slug"></a> at the end of the heading, with a slug of lowercase ASCII letters, digits and single hyphens (error);
  • a slug used by more than one scenario in the same spec (warning).

Tests link to scenarios by slug: @OpenSpec(capability = "user-auth", scenario = "valid-credentials").
